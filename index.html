About me

I’m Abdullah Al Noman, a frontend developer who builds fast, accessible websites.

For me, great frontend work is about more than good looks. It’s about websites that load quickly, work on every screen, and are easy for everyone to use. I build with HTML, CSS, JavaScript, and Tailwind CSS, turning designs into clean, responsive, accessible code that’s easy to maintain. Whether it’s a portfolio, a landing page, or a full web app, I focus on performance, attention to detail, and a smooth user experience.
